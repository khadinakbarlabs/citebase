# E-E-A-T checklist (Citebase)

Score each dimension **1–10**. Real E-E-A-T is shown, not declared. An author bio alone is not enough.

Talk like `plain-language.md` when reporting to the user: say "trust signals" and name the fix, not the acronym, until they ask.

## Experience (has the author done the thing?)
- [ ] First-person specifics ("when we tried X…")
- [ ] Original photos, screenshots, data or failure stories
- [ ] Details a generalist could not invent in 30 minutes
- [ ] Process / workflow, not only outcomes

## Expertise (depth and accuracy)
- [ ] Claims tied to primary sources (or clearly owned as opinion)
- [ ] Correct technical terms and edge cases
- [ ] Willing to disagree with common advice when justified
- [ ] No unverified invented numbers, names or quotes

## Authoritativeness (belongs in the conversation)
- [ ] Page sits in a topical cluster (internal links)
- [ ] Author identity is verifiable beyond one bio line
- [ ] External mentions / citations where relevant
- [ ] Clear track record on this topic

## Trustworthiness (transparency)
- [ ] Limits and what did not work are stated
- [ ] Affiliate / paid relationships disclosed
- [ ] Publish or update date on time-sensitive topics
- [ ] Contact / about path exists; no misleading claims

## Vetoes (block publish until fixed)
- Fabricated credentials, fake reviews, undisclosed paid placement
- Medical / financial / legal advice without qualified review when YMYL
- Copied competitor text or scaled unreviewed AI filler

## Output shape
For each dimension: score, 2–3 evidence quotes, top fix. Then overall 0–40 and a plain verdict: **ship**, **fix then ship**, or **rewrite**.
