# Directory listings (white-hat)

Talk like `../../references/plain-language.md`.

## Vetoes
- Mass auto-submit to spam directories
- Paid link schemes disguised as "directories"
- Fake NAP (name/address/phone) inconsistencies for local

## Web connector mode
Produce the submission sheet in chat. Live competitor/local research: `quote_cost` (pack `local` about $0.15 when relevant) then `call-actor` on `khadinakbar/*` only. Never create accounts or submit without an explicit yes per directory.

## Workflow
1. Collect canonical NAP + website + categories from the user / site.
2. Prioritise **relevant** listings: industry associations, local chambers, app marketplaces, well-known SaaS directories, Google Business Profile (local), Apple/Google maps where applicable.
3. Produce a submission sheet: directory name, URL, why it fits, required fields, whether an editorial review is needed, estimated effort.
4. Draft consistent blurbs from the entity statement library (`entity-seo`).
5. After live research is needed (competitor citations, local pack): `quote_cost` + `khadinakbar/*` only (local pack when relevant).
6. Log completed submissions for the user; never create accounts or submit without explicit approval per site.
7. Done / Cost so far / Next — offer `link-building` for editorial links, `platform-presence` for social/profile surfaces.

## Rules
- Apify auth only via the documented Citebase MCP setup (OAuth or token). No third-party Store Actors.
- Consistency beats volume: fewer accurate listings beat hundreds of junk ones.
